# EasyUtau: 쉬운 조교

OpenUtau의 조교(소리 만드는) 기능을 그대로 쓰면서, 처음 써 보는 사람도 바로 고칠 수 있게 만든 Mac 앱이에요.
악보에서 **빈 곳을 클릭하면 가사 한 글자(섹터)가 생기고**, **마우스로 끌면 음 높이 곡선이 그려지고**,
**우클릭한 곳에서 스페이스를 누르면 거기부터 들려요**. 떨림 · 발음 같은 나머지 조교는 오른쪽 세부 설정 창에서 해요.

AutoTuner(자동 조교)에서 음표를 누르면 이 앱으로 넘어와서 손으로 다듬게 돼요.

## 어떻게 돌아가나요

EasyUtau는 소리를 스스로 만들지 않아요. 내 Mac에 깔린 **OpenUtau의 엔진을 그대로** 써요.

- 가수(음원) · 설정은 OpenUtau와 같이 써요 (`~/Library/OpenUtau`). 따로 설치할 게 없어요.
- 파일은 OpenUtau와 똑같은 `.ustx`예요. EasyUtau에서 고친 걸 OpenUtau에서 열 수 있고, 반대도 돼요.
- 되돌리기(⌘Z)도 OpenUtau의 되돌리기를 그대로 써서, 어떤 고치기든 한 번에 되돌아가요.
- 들어 보기는 OpenUtau와 같은 방식으로 그때그때 소리를 만들어요 (고친 곳만 다시 만들어서 빨라요).

그래서 **OpenUtau가 응용 프로그램 폴더에 있어야** 해요 ([받는 곳](https://github.com/stakira/OpenUtau/releases/latest)).

## 설치

1. OpenUtau(Mac)와 쓰고 싶은 음원을 설치해 둬요.
2. 저장소의 Actions → 최근 빌드 → `EasyUtau-mac`을 받아 풀고 `EasyUtau.app`을 응용 프로그램 폴더로 옮겨요
   (Apple Silicon · 인텔 모두 돼요, macOS 14 이상).
3. 서명 없는 앱이라 처음 한 번은 막혀요. 터미널에 이렇게 한 번만 실행해요:

   ```sh
   xattr -dr com.apple.quarantine /Applications/EasyUtau.app
   ```

직접 만들려면 `mac/build.sh --install` (Xcode 또는 Command Line Tools + .NET SDK 10 필요).

## 쓰는 법

### 트랙 화면 (처음 화면)

- 목소리 덩어리를 **누르면 편집 화면**으로 들어가요 (OpenUtau와 같아요).
- 빈 곳을 누르면 그 자리에 새 노래 덩어리가 생겨요. 끌면 옮기고, 오른쪽 끝을 끌면 길이를 바꿔요.
- 왼쪽에서 가수 · 음소거 · 소리 크기를, 우클릭으로 가수 · 트랙 색 · 지우기를 고를 수 있어요.
- AutoTuner로 만든 결과(`~/Music/AutoTuner`)는 왼쪽 목록에 저절로 나와요.
- 재생할 때 화면은 보던 곳 그대로예요 (**화면 고정**). 재생 위치를 따라 넘어가게 하려면 위의 **따라가기** 단추를 눌러요.

### 편집 화면

- **왼쪽에 음 이름 표**가 있어요 (도 C4처럼). 건반을 누르면 그 음이 들려요.
- **빈 곳을 클릭** → 그 음 높이에 섹터(가사 한 글자)가 생기고 바로 가사를 칠 수 있어요. Return이나 Tab으로 다음 섹터로 넘어가요.
- **섹터를 끌면** 옮기고, 오른쪽 끝을 끌면 길이가 바뀌어요. 더블클릭하면 가사를 고쳐요.
- **섹터 지우기**: 섹터를 눌러 고르고 **⌫**(또는 Delete). 오른쪽 창 위의 휴지통 단추로도 돼요.
  가사 칸이 열려 있을 때는, 방금 만든 섹터는 가사를 치기 전에 ⌫ 하면 없어지고, 원래 있던 섹터는 글자를 다 지운 빈 칸에서 ⌫를 한 번 더 누르면 지워져요.
- **음 높이 곡선**은 악보에서 왼쪽 버튼을 누른 채로 끌면 그려져요 (섹터 도구에서는 빈 곳에서 끌 때, ✎ 도구에서는 어디서나).
  선은 펜이 지나간 곳 그대로 가고 (음표 경계 · 떨림이 있어도), 손 떨림은 살짝 고르고, 그린 곳 양 끝은 원래 선으로 부드럽게 이어져요.
  음 높이 도구(2)에서 **선을 잡아 끌면** 그 자리에 점이 생기고 거기서 접혀요 (OpenUtau 음 높이 점과 같아요). 섹터 사이 이음 표시로 앞 섹터와 잇거나 끊어요.
  지우개로 지우면 섹터가 만드는 높이로 돌아가요. 세부 설정 창의 **음 높이 부드럽게**는 고른 섹터의 잔떨림을 골라요.
- **우클릭하면 재생 시작점**이 거기로 옮겨지고, **스페이스**를 누르면 그 자리부터 지금 작업물이 들려요.
- **오른쪽 세부 설정 창**: 떨림(비브라토), 음 넘어가는 모양, 발음(음원의 어떤 소리로 부를지), 소리 크기 · 숨소리 같은 설정,
  구간 전체에 넣는 곡선(세기 · 숨소리 · 힘줌).
- 가사를 한꺼번에 붙여 넣으면 음절마다 섹터에 차례로 들어가요 (한글 한 글자, 가나 한 글자, 영어는 단어 하나).

### 단축키

| 키 | 하는 일 |
| --- | --- |
| 1 · 2 · 3 | 섹터 · 음 높이 · 지우개 도구 |
| ⌥ + 끌기 | 섹터 복제 |
| Space | 고른 시작점부터 듣기 / 멈추기 |
| Return | 고른 섹터의 가사 |
| ↑ ↓ | 반음 올리기 · 내리기 (⇧는 옥타브) |
| ← → | 한 칸 옮기기 |
| S | 섹터 나누기 |
| ⌫ · Delete | 고른 섹터 지우기 |
| ⌘Z · ⌘Y (⌘⇧Z) | 되돌리기 · 다시 하기 (가사 칸에 커서가 있어도 돼요) |
| ⌘S · ⌘⇧S | 저장 · 다른 이름으로 |
| ⌘E | wav로 내보내기 |
| ⌘0 | 세부 설정 창 열고 닫기 |
| ⌘ + 스크롤 | 가로 크기, ⌥ + 스크롤은 세로 크기 |

### 다른 앱과 같은 파일 쓰기

- EasyUtau · OpenUtau · AutoTuner는 같은 `.ustx`를 그대로 열고 저장해요.
- 연 파일을 OpenUtau나 AutoTuner가 고치면, EasyUtau로 돌아올 때 알아서 다시 읽어요
  (여기서 고친 것이 저장 안 된 채 남아 있으면 어느 쪽을 쓸지 물어봐요). 저장할 때도 그사이 바뀌었으면 덮어쓸지 물어봐요.
- **OpenUtau에서 열기**는 저장한 뒤 OpenUtau를 그 파일로 켜요. OpenUtau가 이미 켜져 있으면 Finder에서 파일을 보여 줘요
  (OpenUtau는 켤 때만 파일을 받아요).
- AutoTuner는 EasyUtau에서 고친 걸 알아채고 결과 화면의 음표를 맞춰요. 테토 미리 듣기는 "다시 불러 보기"로 새로 만들 수 있어요.

## 만든 구조

| 폴더 | 하는 일 |
| --- | --- |
| `engine/` | C# 엔진. OpenUtau.Core를 그대로 쓰면서 앱과 표준 입출력으로 JSON 한 줄씩 주고받아요 (열기 · 고치기 · 되돌리기 · 재생 · 내보내기). |
| `mac/Sources/EasyUtau/` | SwiftUI · AppKit 앱. 악보(`PianoRoll.swift`)와 트랙 화면(`TracksView.swift`)은 빠르게 돌도록 직접 그려요. |
| `devtools/` | CI와 손 시험용 도구 (엔진 폴더 준비, 엔진 시험, 음원 설치). |
| `.github/workflows/mac.yml` | macOS에서 앱을 만들고, 실제 음원으로 엔진을 시험해요 (소리 파일은 올리지 않아요). |

음 높이 계산(`Pitch.swift`)은 OpenUtau의 식을 그대로 옮겨서, 화면의 주황색 선이 실제로 부르는 높이와 같아요.
